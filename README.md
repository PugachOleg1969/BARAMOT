# Принц с Барамота — интеграционный baseline v2.2

Flutter/Android-прототип детской игры о финансовой грамотности для хакатона ЛЦТ 2026.

## Текущая контрольная точка

Этот пакет собран из актуального снимка проекта от 23.09.2026. На этом шаге намеренно исправлены только изменения, которые не требуют пересмотра утверждённой экономики:

- глобальный сброс очищает и основной профиль, и отдельное состояние BAZAR;
- первое подтверждение Плана сразу создаёт `currentPlan`, поэтому состояние до и после перезапуска больше не расходится;
- BAZAR использует тот же экземпляр `BazarGameStorage`, которым управляет корневой экран;
- AstroBox больше не является скрытым постоянным складом: он бесплатно очищает остаток текущего рейса и не меняет баланс;
- старое сохранённое `astroBoxCargo` при загрузке намеренно не восстанавливается;
- в первом Совещании закреплена роль Ии как суфлёра: она объясняет, но решение принимает Командор;
- исправлено битое описание проекта в `pubspec.yaml`.

## Почему это отдельная контрольная точка

Перед подключением предметного Плана, реальных покупок, трёх целей и пяти периодов найден конфликт в экономике, который нельзя молча разрешать в коде:

- стартовый капитал: 12 Дар;
- обязательное содержание Барри + питомца в текущем каталоге: 6 Дар за период;
- текущая цена/цель датчика топлива в коде: 12 Дар;
- в старом сценарии зафиксирован иной первый выбор с датчиком.

До решения этого конфликта не следует переписывать первый игровой период.
