# Принц с Барамота

Обучающая игра о финансовой грамотности для детей 7–11 лет.
Android-приложение на Flutter, работает полностью без интернета.

Проект команды «Барамот» для хакатона **ЛЦТ 2026**, задача «Питомец Финни» (Департамент финансов города Москвы).

## Об игре

Корабль Барри потерпел аварию возле Базы. Игрок — Командор Базы — вместе с командой и питомцем помогает его починить. Каждый игровой день устроен как настоящий финансовый цикл:

1. **Утро — План.** Командор распределяет бюджет дня по трём направлениям и отделяет обязательное («НАДО») от желаемого («ХОЧУ»).
2. **День — работа.** Игровая валюта «Дар» зарабатывается трудом на квестах рынка BAZAR.
3. **Вечер — Факт.** План сверяется с тем, что получилось на деле, часть Дар откладывается в накопления.

Итог игры зависит от решений игрока. Если ремонт корабля (67 Дар) удалось оплатить, корабль улетает сам. Если нет, его увозит техничка. В обоих финалах Сверчок прощается с Командором от имени всей команды.

«Дар» — только игровая единица. Её нельзя купить или обменять на реальные деньги.

## Чему учит

Три темы из ТЗ:

- 📋 **Планирование бюджета** — «НАДО» и «ХОЧУ», План и Факт, бюджет дня с контролем остатка;
- 🐷 **Формирование сбережений** — три цели накоплений, снятие с подтверждением, рост копилки;
- 🛒 **Платежи и покупки** — сравнение цен, влияние покупок на питомца, что делать, если не хватает.

## Возможности

- **Питомец на выбор:** Скороход, Квак или Цветик-Семицветик. У каждого три образа. Питомец растёт, когда игрок оплачивает обязательное, следует Плану и откладывает Дар.
- **Школа командиров** — неоновая вывеска на Базе. Шесть финансовых заданий по трём темам; пояснение показывается к любому варианту, задание можно пройти снова. За первое прохождение — Дар, за каждые два задания — ранг: Слушатель курсов → Командир 1-го ранга → Командир 2-го ранга → **Профи**.
- **Три цели накоплений:** «Подарок Питомцу» (8 Дар), «Датчик топлива» (12), «Телескоп для Базы» (20).
- **Итоги дня:** сияние питомца, звёзды за хорошие решения.
- **Справочная с Пчелой** — подсказки по игре.
- **Весёлый тир** — мини-игра для отдыха внутри приложения, в альбомной ориентации. На Дар и питомца не влияет.
- **Раздел для взрослого** под защитой простого примера: прогресс ребёнка, темы и компетенции, звук и анимации, сброс прогресса, тестовый профиль «ДЕМО» для быстрой проверки.
- **Первый запуск:** согласие взрослого, Политика конфиденциальности и Пользовательское соглашение.

## Безопасность и данные

- Приложение не запрашивает имя, возраст, телефон, почту, фото и геолокацию. Игрок вводит только прозвище Командора и имя питомца.
- Прогресс хранится **только на устройстве** (`shared_preferences`) и никуда не передаётся.
- Нет рекламы, аналитики, отслеживания и платных покупок.
- Все картинки, видео и мини-игры лежат внутри приложения. В основном манифесте Android нет разрешения на доступ к интернету.
- Удалить все данные можно кнопкой сброса в разделе для взрослого или удалив приложение.

## Демонстрационный режим (для экспертной проверки)

1. Запустите приложение, взрослый отмечает согласие на титульном экране.
2. Пройдите короткое знакомство до Базы (прозвище Командора, питомец, имя).
3. На Базе в меню откройте **«Для взрослого»** и решите пример на умножение.
4. Нажмите **«Загрузить тестовый профиль»** и подтвердите.

Тестовый профиль: База, утро первого дня, **30 Дар**, питомец Квак; на Базе видна отметка «ДЕМО». Все 5 игровых дней проходятся подряд, без ожидания реального времени; задания Школы командиров доступны сразу. Повторная загрузка тестового профиля возвращает его в исходное состояние.

## Сброс и удаление профиля

База → **«Для взрослого»** → пример → **«Сбросить и удалить профиль»** → подтвердить. Удаляются прогресс и состояние рынка BAZAR; настройки звука и анимаций сохраняются. Полное удаление — удалить приложение с устройства.

## Установка

Подписанный релизный APK прикладывается к релизу `v1.0.0` в разделе **Releases** этого репозитория.

1. Скачайте `app-release.apk` на телефон.
2. Разрешите установку из этого источника, если Android попросит.
3. Установите и запустите. При первом запуске взрослый подтверждает согласие с документами.

## Сборка из исходников

**Нужно:**
- Flutter, канал stable (Dart SDK 3.11.5 и новее);
- JDK 17;
- Android SDK.

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.

### Подпись релиза

Ключ подписи и пароли в репозиторий не входят. Если файла `android/key.properties` нет, релизная сборка **не падает**, а подписывается отладочным ключом. Так проект можно собрать и проверить сразу после клонирования.

Чтобы подписать своим ключом, создайте `android/key.properties`:

```properties
storePassword=<пароль хранилища>
keyPassword=<пароль ключа>
keyAlias=<псевдоним ключа>
storeFile=<полный путь к файлу .jks, через прямые слеши>
```

## Шпаргалка: проверка и сборка

Все команды — из корня проекта.

| Что сделать | Команда |
|---|---|
| Скачать зависимости | `flutter pub get` |
| Проверить код (ожидается «No issues found!») | `flutter analyze` |
| Запустить все тесты (ожидается «+95: All tests passed!») | `flutter test` |
| Один файл тестов | `flutter test test/commander_school_test.dart` |
| Запустить на подключённом телефоне (отладка) | `flutter run` |
| Отладочный APK | `flutter build apk --debug` |
| Релизный APK | `flutter build apk --release` |
| Поставить релиз на телефон | `flutter install --release` |
| Проверить подпись APK | `apksigner verify --print-certs build/app/outputs/flutter-apk/app-release.apk` |
| Проверить окружение | `flutter doctor -v` |

`apksigner` лежит в Android SDK: `build-tools/<версия>/apksigner` (на Windows — `apksigner.bat`).
