# Ассеты «Принц с Барамота» — перечень и права

Редакция от 26.09.2026. Версия приложения 1.0.0.

## Правообладатель

Все файлы из папки `assets/` созданы **Пугачом Олегом Юрьевичем** для приложения «Принц с Барамота». Правообладатель — Пугач Олег Юрьевич.

## Как созданы

Изображения, видео и звук созданы автором с помощью инструментов искусственного интеллекта. Замысел, персонажи, описания для генерации, отбор результатов и доработка выполнены автором.

Использованные общедоступные инструменты:
- локальные языковые модели (LLM), запущенные через Ollama на собственном оборудовании автора;
- Grok (xAI, подписка SuperGrok);
- NightCafe Studio.

Условия Grok и NightCafe оставляют права на созданные материалы за пользователем и допускают их коммерческое использование. Использование Grok указано здесь в соответствии с требованием xAI указывать сервис при использовании созданных в нём материалов.

Мини-игра «Весёлый тир» (`tir/vesely-tir.html`) создана автором для этого приложения.

Сторонние стоковые изображения, музыка, звуки и шрифты в папке `assets/` не используются.

## Работа без интернета

Все ассеты входят в приложение и загружаются с устройства. «Весёлый тир» — один HTML-файл без внешних ссылок, скриптов и шрифтов. Он открывается во встроенном WebView без доступа к сети.

## Как добавить ассет

1. Положите файл в нужную папку внутри `assets/`.
2. Если папка новая, добавьте её в раздел `flutter: assets:` файла `pubspec.yaml`.
3. Допишите файл в этот перечень с описанием и источником.
